## [1.0.0] - 2026-07-17

### Added
- Initial website implementation based on Kushel Wellness Club Brand Bible.
- Home page with hero section, pillars, journey, benefits, and call to actions.
- About page with mission, vision, values, and lead coach profile.
- Experiences (Programs) page detailing weekly events and specialized sessions.
- Wellness Tools page with functional BMI, Water Intake, Protein, and Daily Calories calculators.
- Success Stories page showcasing community transformations.
- FAQ page with interactive accordion layout.
- Contact page with WhatsApp integration and form.
- Privacy Policy and Terms & Conditions pages.
- Technical architecture including responsive CSS, CSS variables, and SEO configuration (robots.txt, sitemap.xml).
